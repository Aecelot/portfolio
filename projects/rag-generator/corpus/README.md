# Sample corpus

Four chapters from Sir Thomas Malory, *King Arthur and the Knights of the Round Table*, edited by
Rupert S. Holland (1919), taken from Project Gutenberg eBook #36462. The text is in the public domain in
the United States, and the Project Gutenberg licence and trademark notices have been removed from the
excerpts. See https://www.gutenberg.org/ebooks/36462 for the full book and licence.

These files replace the private game-world lore the original prototype was built on, so that the
pipeline can be run by anyone.
